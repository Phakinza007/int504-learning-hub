# INT504 Learning & Project Hub (`itb-csv`)

Interactive study guide, Excalidraw architecture diagrams, Sprint 1–3 PBI explorer, API & Database reference, Interactive Simulators, and Quiz for **INT504 Integrated Project (itb-csv)**.

## Features
- **Overview & Timeline** — Course schedule, 4-container architecture, team roles (Alan / Beam / Dragon)
- **6 Excalidraw Diagrams** (rendered via `@excalidraw/cli` in Light SVG, Dark SVG, and editable `.excalidraw` scenes)
- **7 Structured Lessons** — From 4-layer Backend & Prisma to Validation (`application/problem+json`), Clash Detection, Keycloak JWKS Auth, and Docker/Nginx Deploy
- **PBI 1–12 Explorer** — Filter by Sprint/Owner, search, expand edge cases, track progress in `localStorage`
- **API & DB Reference** — All Sprint 1–3 endpoints and MySQL/Prisma tables
- **Interactive Lab** — Student ID Decoder, Schedule Clash Checker (PBI 11), Fixed vs Option Tester (PBI 4)
- **12-Question Quiz** — Real test-case traps with instant explanations

## Local Preview
Open `index.html` directly in your browser, or run:
```bash
python3 -m http.server 8080 -d ~/int504-learning-hub
```
